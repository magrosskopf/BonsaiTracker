# System reminder origin and removal

Care-plan reminders are distinct system reminders, not ordinary user-created reminders. Users may mark a system reminder as done, snooze it through constrained actions, or remove it from active planning, but they may not freely edit it. Each system reminder stores care-plan origin data: `source=CARE_PLAN`, `carePlanVersion`, `speciesId`, `ruleId`, and `targetMonth`. Removal is recorded as a cancelled reminder so later care-plan synchronization does not silently recreate a suggestion the user already rejected. Care-plan synchronization is idempotent: for a bonsai, care-plan version, rule, and target month, there is at most one active system reminder, and completed or removed system reminders are not recreated. If a care plan is explicitly replaced after the curated species changes, open system reminders from the old plan are cancelled while completed system reminders remain as history.
